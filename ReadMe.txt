The repository contains different versions of the study application. The main branch contains the complete Unreal Engine project and therefore the source project of the developed study. The build branch contains the executable version of the study in the form in which it was provided to participants during data collection.

The provided executable versions are builds for Microsoft Windows. Executable versions for other operating systems were not provided as part of the study.

In addition, the intervention and control branches are available. Each of these contains an executable version of the study application with a predefined experimental condition. The intervention branch contains only the intervention condition, whereas the control branch contains only the control condition. This makes it possible to reproduce and examine the respective experimental condition independently of the group assignment used in the regular study version.

Furthermore, the admin branch is available. It contains an administrative version of the application that can be used to decrypt the encrypted data stored for the study participants and subsequently export it as a text file (.txt).



Das Repository enthält verschiedene Versionen der Studienanwendung. Der Branch main enthält das vollständige Unreal-Engine-Projekt und damit das Quellprojekt der entwickelten Studie. Der Branch build enthält die ausführbare Version der Studie in der Form, in der sie den Probanden während der Datenerhebung zur Verfügung gestellt wurde.

Bei den bereitgestellten ausführbaren Versionen handelt es sich um Builds für Microsoft Windows. Ausführbare Versionen für andere Betriebssysteme wurden im Rahmen der Studie nicht bereitgestellt.

Zusätzlich stehen die Branches intervention und control zur Verfügung. Diese enthalten jeweils eine ausführbare Version der Studienanwendung mit fest vorgegebener Versuchsbedingung. Der Branch intervention enthält ausschließlich die Interventionsbedingung, während der Branch control ausschließlich die Kontrollbedingung enthält. Dadurch kann die jeweilige Versuchsbedingung unabhängig von der Gruppenzuweisung der regulären Studienversion reproduziert und betrachtet werden.

Darüber hinaus steht der Branch admin zur Verfügung. Dieser enthält eine administrative Version der Anwendung, mit der die verschlüsselt gespeicherten Daten der Studienteilnehmer entschlüsselt und anschließend in Form einer Textdatei (.txt) ausgegeben werden können.
