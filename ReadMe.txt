To decrypt and view files in the Admin version, the corresponding SaveGame folder from the regular version must first be copied.

The folder is located at:

`Windows/MasterThesisStudy/Saved/SaveGames`

The SaveGames folder then needs to be copied to the same location in the Admin version, replacing the existing folder if necessary.

Once the SaveGame data has been transferred successfully, an additional Admin button will appear in the upper-left corner of the Settings menu.

The Admin section allows the stored data to be viewed and exported.

For each exported file, a separate folder is created inside the SaveGames folder. This folder contains the corresponding exported and decrypted data.



Um Dateien in der Admin-Version entschlüsseln und einsehen zu können, muss zunächst der entsprechende SaveGame-Ordner aus der normalen Version kopiert werden.

Der Ordner befindet sich unter:

`Windows/MasterThesisStudy/Saved/SaveGames`

Dieser SaveGames-Ordner muss anschließend an derselben Stelle in der Admin-Version eingefügt bzw. ersetzt werden.

Nachdem die SaveGame-Daten erfolgreich übernommen wurden, erscheint im Settings-Menü oben links ein zusätzlicher Admin-Button.

Über diesen Admin-Bereich können die gespeicherten Daten eingesehen und anschließend exportiert werden.

Für jede exportierte Datei wird im SaveGames-Ordner ein eigener Ordner erstellt. In diesem Ordner befinden sich die jeweiligen exportierten und entschlüsselten Daten.
